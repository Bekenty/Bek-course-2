### 📌 Номер и условия вариантов

* **Задание №7 (Базовый уровень):** Выбор языка интерфейса: сохранять выбранный язык и отображать соответствующие подписи с помощью `localStorage`.


* **Задание №9 (Средний уровень):** Учет расходов (категория, сумма, дата) с сохранением операций в виде массива объектов через `JSON.stringify()` и вычислением общего расхода.


* **Задание №18 (Повышенный уровень):** Система бронирования учебных комнат (дата, время, помещение) с сохранением записей и предупреждением пользователя о конфликтах при попытке забронировать занятый слот.



---

### 🎯 Цель работы

Освоить сериализацию и десериализацию объектов JavaScript в формат JSON, хранение данных в `localStorage` и `sessionStorage`, восстановление интерфейса после обновления страницы, а также удаление сохраненных записей. Научиться работать с методами `setItem()`, `getItem()`, обрабатывать отсутствие данных и поврежденный JSON с помощью конструкций `try...catch` без аварийного завершения приложения.

### ⚙️ Входные и выходные данные

* **Задание №7 (Базовый уровень):**
* *Входные данные:* Выбранный язык интерфейса из выпадающего списка (русский, английский, казахский).
* *Выходные данные:* Динамическое изменение текстовых меток интерфейса на странице и сохранение выбранного языка в `localStorage`.




* **Задание №9 (Средний уровень):**
* *Входные данные:* Выбранная категория расхода, числовое значение суммы, дата транзакции, действия добавления/удаления.
* *Выходные данные:* Массив объектов расходов, сериализованный в JSON-строку и записанный в `localStorage`. Динамический пересчет и вывод общей суммы расходов.




* **Задание №18 (Повышенный уровень):**
* *Входные данные:* Выбранная учебная аудитория, дата, временной слот, введенные данные пользователя.
* *Выходные данные:* Проверка массива существующих броней на наличие коллизий (конфликтов). Запись новой брони в `localStorage` или вывод предупреждающего модального окна.

### 🛠️ Алгоритм решения

1. **Разметка интерфейса (HTML5):** Создание адаптивных интерфейсов для каждого из выбранных вариантов с использованием семантических тегов и элементов управления.
2. **Оформление и интерактивность (CSS3):** Разработка современного дизайна с применением CSS-переменных, адаптивных сеток (Grid/Flexbox) и плавных анимаций.
3. **Логика JavaScript и Web Storage:**

* *Вариант №7:* Чтение сохраненного языкового пакета при инициализации страницы, мгновенное обновление атрибутов `data-i18n` и запись настроек через `JSON.stringify()`.
* *Вариант №9:* Безопасная десериализация данных через `JSON.parse()` в блоке `try...catch`, добавление транзакций в массив объектов и сохранение через `JSON.stringify()`.


* *Вариант №18:* Использование метода `Array.prototype.some()` для детекции пересечений бронирования по аудитории, дате и времени.
