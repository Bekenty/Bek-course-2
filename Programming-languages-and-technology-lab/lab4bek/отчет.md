Ответы на контрольные вопросы (Лабораторная работа №4)
Что такое HTML-форма?Это специальная область на веб-странице, содержащая элементы управления (текстовые поля, кнопки, переключатели), которая предназначена для сбора пользовательских данных и их последующей отправки на сервер. 
  Для чего используются элементы input, select и button?<input> — универсальный элемент для ввода данных (текст, почта, пароли, галочки, радиокнопки).<select> — создает выпадающий список вариантов выбора.<button> — создает интерактивную кнопку (например, для отправки формы type="submit").Чем checkbox отличается от разрешенного выбора в radio?checkbox (флажок) позволяет пользователю выбрать несколько независимых вариантов (или ни одного).radio (переключатель) объединяется в группу по общему имени (name) и позволяет выбрать только один вариант из предложенных.
  Что такое клиентская валидация?Это проверка правильности заполнения формы, которая выполняется непосредственно в браузере пользователя с помощью JavaScript (или встроенных HTML5-атрибутов) до отправки данных на сервер.  
   Для чего используется событие submit?Событие submit возникает в момент попытки отправки формы (когда пользователь нажимает кнопку отправки или клавишу Enter внутри формы). Его используют для перехвата отправки и запуска проверки.
   Что делает event.preventDefault()?Отменяет стандартное поведение браузера по умолчанию. В случае с формой он останавливает её автоматическую отправку и перезагрузку страницы, позволяя сначала выполнить JavaScript-проверку.  
    Как получить значение текстового поля в JavaScript?С помощью обращения к элементу через его ID и считывания свойства .value, например: document.getElementById('name').value.Как проверить состояние checkbox?С помощью обращения к элементу и проверки логического свойства .checked (возвращает true, если галочка стоит, и false, если нет), например: document.getElementById('agree').checked.
    Как получить выбранное значение select?Точно так же, как и текстовое поле, через свойство .value самого элемента <select>. Браузер вернет значение атрибута value выбранного в данный момент тега <option>.   
    Почему клиентская валидация не заменяет серверную?Клиентская валидация легко обходится пользователем (можно отключить JavaScript в браузере или отправить запрос напрямую через сторонние утилиты). Серверная валидация обязательна для обеспечения безопасности, целостности и защиты базы данных. 
      Как сделать сообщение об ошибке понятным пользователю?Сообщение должно быть написано на человеческом языке, четко указывать на конкретную ошибку и объяснять, что именно нужно исправить (например, не просто «Ошибка ввода», а «Пароль должен содержать не менее 8 символов»).Какие тестовые случаи следует проверить для формы?Как минимум:Успешная отправка при корректном заполнении всех полей.Попытка отправки полностью пустой формы.Проверка каждого обязательного поля по отдельности (оставление его пустым).Ввод некорректных данных (например, неверный формат email или слишком короткий пароль).
