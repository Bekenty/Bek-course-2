Контрольные вопросы по лабаротории 2 Жарас Бек ИС 25 22

1. **Что представляет собой переменная в Python?**
Это именованная ячейка памяти, в которой хранятся данные (числа, текст и т.д.).
2. **Какие основные типы данных используются в Python?**
Основные: `int` (целые числа), `float` (дробные числа), `str` (строки/текст) и `bool` (логический тип: `True`/`False`).
3. **Чем int отличается от float?**
`int` хранит только целые числа (например, `5`), а `float` — числа с плавающей точкой, то есть с дробной частью (например, `5.5`).
4. **Как работает функция input()?**
Она останавливает выполнение программы, ждет ввода текста с клавиатуры и возвращает введенное значение в виде строки (`str`).
5. **Почему результат input() часто необходимо преобразовывать?**
Потому что `input()` всегда возвращает строку. Выполнять с ней математические операции (сложение, умножение как с числами) нельзя без предварительного преобразования.
6. **Для чего используются int() и float()?**
Для конвертации данных (например, строк) в числовой формат: `int()` — в целое число, `float()` — в дробное.
7. **Чем / отличается от //?**
`/` выполняет обычное деление с получением дроби (например, `5 / 2 = 2.5`), а `//` — целочисленное деление, отбрасывая дробную часть (например, `5 // 2 = 2`).
8. **Что делает оператор %?**
Возвращает остаток от деления одного числа на другое (например, `5 % 2 = 1`).
9. Для чего используется оператор **?**
Для возведения числа в степень (например, `2 ** 3` означает 2 в кубе, результат — `8`).
10. **Как определить тип переменной с помощью type()?**
Вызвать функцию `type()`, передав ей переменную: `print(type(x))`.
11. **Что такое преобразование типов?**
Это процесс изменения типа данных переменной (например, превращение строки в число) с помощью специальных функций вроде `int()`, `float()`, `str()`.
12. **Что произойдет при попытке int("Python")?**
Произойдет ошибка (`ValueError`), так как текстовую строку, не состоящую из цифр, невозможно перевести в целое число.
13. **Как получить последнюю цифру целого числа?**
Использовать оператор остатка от деления на 10: `x % 10`.
14. **Как удалить последнюю цифру целого числа?**
Использовать целочисленное деление на 10: `x // 10`.
15. **Почему выбор правильного типа данных важен?**
От этого зависит корректность работы программы. Например, сложение строк `"5" + "5"` даст склейку `"55"`, а сложение чисел `5 + 5` выполнит математическое сложение и даст `10`.
