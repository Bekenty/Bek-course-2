Ответы на контрольные вопросы (Раздел 8)
Для чего используется JavaScript в браузере?
JavaScript используется для создания интерактивных и динамических веб-страниц. Он позволяет обрабатывать действия пользователя (клики, ввод текста), манипулировать содержимым и стилями DOM-дерева, отправлять запросы на сервер без перезагрузки страницы (AJAX/Fetch) и валидировать формы.

Чем let отличается от const?

let позволяет объявлять переменные, значение которых можно переопределять в процессе выполнения программы.

const объявляет константы — переменные, значение которых нельзя переопределить после инициализации. При этом оба ключевых слова имеют блочную область видимости.

Что такое условный оператор?
Условный оператор (if...else, switch) — это конструкция языка, которая выполняет определенный блок кода в зависимости от того, истинно (true) или ложно (false) заданное логическое выражение.

Какие циклы есть в JavaScript?
Основные циклы: for (классический цикл с счетчиком), while (выполняется, пока условие истинно), do...while (выполняет тело хотя бы один раз перед проверкой условия), а также специальный цикл for...of (для перебора элементов массивов) и for...in (для перебора ключей объектов).

Что такое функция и параметр функции?

Функция — это переиспользуемый блок кода, предназначенный для выполнения конкретной задачи.

Параметр функции — это переменная, указанная в объявлении функции, которая принимает конкретное значение (аргумент) при её вызове.

Что такое DOM?
DOM (Document Object Model) — это объектная модель документа, представление HTML-структуры страницы в виде дерева объектов JavaScript. Каждая тег-структура является отдельным узлом (node), с которым можно взаимодействовать через код.

Как получить HTML-элемент в JavaScript?
Для поиска элементов используются методы DOM:

document.querySelector('#id') или document.querySelector('.class') — находит первый подходящий элемент по CSS-селектору.

document.getElementById('id') — находит элемент по идентификатору.

document.querySelectorAll('selector') — находит список всех элементов по селектору.
