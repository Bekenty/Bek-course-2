📐 СЛАЙД 2: Задание №2 — Прямоугольник

Условие: Введите длину и ширину прямоугольника. Найдите его площадь и периметр.

🔍 Разбор слайда — алгоритм и математика

Для вычисления площади используется формула:

S = a * b

Для вычисления периметра:

P = 2 * (a + b)

Фрагмент кода:

S = a * b
P = 2 * (a + b)

print(f"Площадь (S): {S:.2f}")
print(f"Периметр (P): {P:.2f}")

🖥️ Демонстрация работы — Тест 1:

► Введите длину прямоугольника: 5.5
► Введите ширину прямоугольника: 4

-------------------------------------------------------
✔ Результаты вычислений:
  • Площадь (S) : 22.00
  • Периметр (P): 19.00
-------------------------------------------------------

Результат: программа корректно рассчитывает площадь и периметр прямоугольника.


🔢 СЛАЙД 3: Задание №10 — Поразрядный разбор числа

Условие: Введите четырехзначное число. Выведите его цифры по отдельности: тысячи, сотни, десятки и единицы.

🔍 Разбор слайда — целочисленная математика

Для получения отдельных цифр используются операции целочисленного деления // и остатка от деления %.

Фрагмент кода:

thousands = num // 1000
hundreds = (num % 1000) // 100
tens = (num % 100) // 10
units = num % 10

При этом строки не используются — число обрабатывается только математическими операциями.

🖥️ Демонстрация работы — Тест 2:

► Введите четырехзначное целое число: 4567

-------------------------------------------------------
✔ Выделенные разряды:
  • Тысячи  : 4
  • Сотни   : 5
  • Десятки : 6
  • Единицы : 7
-------------------------------------------------------

Результат: цифры числа 4567 успешно выделены по отдельным разрядам.


📐 СЛАЙД 4: Задание №19 — Прямоугольный треугольник

Условие: Введите катеты прямоугольного треугольника. Найдите гипотенузу, площадь, периметр и два острых угла в градусах.

🔍 Разбор слайда — математические формулы

Гипотенуза находится по теореме Пифагора:

c = math.sqrt(a ** 2 + b ** 2)

Площадь треугольника:

S = (a * b) / 2

Периметр:

P = a + b + c

Для вычисления углов используются функции atan() и degrees():

angle_a = math.degrees(math.atan(a / b))
angle_b = math.degrees(math.atan(b / a))

🖥️ Демонстрация работы — Тест 3:

Для проверки возьмем катеты 3 и 4:

► Введите первый катет: 3
► Введите второй катет: 4

-------------------------------------------------------
✔ Результаты вычислений:
  • Гипотенуза : 5.00
  • Площадь    : 6.00
  • Периметр   : 12.00
  • Угол 1     : 36.87°
  • Угол 2     : 53.13°
-------------------------------------------------------

Результат: программа корректно вычисляет гипотенузу, площадь, периметр и два острых угла прямоугольного треугольника.
